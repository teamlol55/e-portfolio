# e-Portfolio · ธนกฤต เรืองเดช

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (e-Portfolio) ของนักเรียนสาขาเทคโนโลยีสารสนเทศ โรงเรียนธัญรัตน์
สร้างด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งโปรแกรมเพิ่ม และเผยแพร่ผ่าน GitHub Pages ได้ทันที

## คุณสมบัติ

- ดีไซน์แบบ Minimal โทนสีขาว ดำ เทา
- เมนูนำทางที่กดแล้วเลื่อนไปยังแต่ละส่วนอย่างนุ่มนวล และไฮไลต์ส่วนที่กำลังดูอยู่
- Animation เล็กน้อย: ชื่อบนหน้าแรกเลื่อนขึ้น, ส่วนต่าง ๆ ค่อย ๆ ปรากฏเมื่อเลื่อนถึง, Hover Effect บนเมนู การ์ด และปุ่ม
- รองรับทั้งคอมพิวเตอร์และโทรศัพท์มือถือ (Responsive) พร้อมเมนูแฮมเบอร์เกอร์
- ปิด Animation อัตโนมัติสำหรับผู้ที่ตั้งค่าลดการเคลื่อนไหวในอุปกรณ์
- รูปทั้งหมดเป็น SVG ฝังในไฟล์ จึงแสดงผลได้เสมอ ไม่ต้องพึ่งไฟล์รูปภายนอก

## โครงสร้างไฟล์

```
e-portfolio/
├── index.html   โครงสร้างและเนื้อหาของเว็บไซต์
├── style.css    การออกแบบ สี ฟอนต์ และ Responsive
├── script.js    เมนูมือถือ, ไฮไลต์เมนู, เอฟเฟกต์เลื่อนปรากฏ
└── README.md    ไฟล์นี้
```

Home · About Me · Education · Skills · Projects · Contact · Footer

## วิธีใช้งานบนเครื่อง

1. ดาวน์โหลดทั้ง 4 ไฟล์มาไว้ในโฟลเดอร์เดียวกัน
2. ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์
3. ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์จาก Google Fonts (หากไม่มีเน็ต เว็บจะใช้ฟอนต์สำรองของเครื่องแทน)

## วิธีแก้ไขข้อมูล

ข้อความสีเทาตัวเอียงในวงเล็บเหลี่ยม เช่น `[ใส่ประวัติส่วนตัว...]` คือช่องที่ต้องแก้เป็นข้อมูลจริงของคุณ
ใน `index.html` ให้ค้นหาคำว่า `todo` หรือเครื่องหมาย `[` แล้วแก้ไขทีละจุด
เมื่อใส่ข้อมูลจริงแล้ว ให้ **ลบคำว่า `todo` ออกจาก `class`** เพื่อให้ข้อความกลับเป็นสีปกติ

| ส่วน | สิ่งที่ต้องแก้ |
|------|----------------|
| About Me | ประวัติส่วนตัว ความสนใจ วันเกิด (ลบแถวที่ไม่ต้องการได้) |
| Education | ปีที่ศึกษา ระดับชั้น และสถาบันก่อนหน้า (คัดลอกบล็อก `<li class="timeline-item">` เพื่อเพิ่ม) |
| Skills | เพิ่มหรือแก้ทักษะ (คัดลอกบล็อก `<li class="skill">`) |
| Projects | ชื่อโครงงาน รายละเอียด เทคโนโลยีที่ใช้ และลิงก์ GitHub |
| Contact | อีเมลและช่องทางติดต่ออื่น ๆ |

### เปลี่ยนสีและฟอนต์

แก้ตัวแปรที่ส่วนบนสุดของ `style.css` (`:root`) เช่น `--ink` (สีตัวอักษรหลัก), `--bg-alt` (สีพื้นหลังสลับ), `--font-head` (ฟอนต์หัวข้อ)

### ใช้รูปโปรไฟล์จริง

1. สร้างโฟลเดอร์ `images/` แล้วใส่รูป เช่น `images/profile.jpg` (ควรเป็นรูปจัตุรัส)
2. ใน `index.html` แทนที่ `<svg ...> ... </svg>` ภายใน `<div class="avatar">` ด้วย

```html
<img src="images/profile.jpg" alt="รูปโปรไฟล์ ธนกฤต เรืองเดช">
```

3. เพิ่มกฎนี้ใน `style.css`

```css
.avatar img { width: 100%; aspect-ratio: 1; object-fit: cover; border-radius: 50%; }
```

### ใช้ภาพจริงของโครงงาน

ใน `index.html` แทนที่ `<svg>` ภายใน `<div class="project-thumb">` ด้วย `<img src="images/project1.jpg" alt="...">` แล้วเพิ่ม `width:100%; height:100%; object-fit:cover;` ให้ `.project-thumb img` ใน CSS

## วิธีเผยแพร่บน GitHub Pages

### 1) อัปโหลดไฟล์ขึ้น GitHub

**วิธีที่ง่ายที่สุด (ผ่านเว็บ ไม่ต้องใช้คำสั่ง)**

1. เข้า <https://github.com> แล้วล็อกอิน
2. เปิด Repository **`e-portfolio`** (หรือสร้างใหม่ที่ **New repository** ตั้งเป็น **Public**)
3. กด **Add file → Upload files**
4. ลากไฟล์ `index.html`, `style.css`, `script.js`, `README.md` (และโฟลเดอร์ `images/` ถ้ามี) ไปวาง
5. ช่อง Commit message พิมพ์ เช่น `Add e-portfolio website` แล้วกด **Commit changes**

> ไฟล์ `index.html` ต้องอยู่ที่ระดับนอกสุดของ Repository (ไม่อยู่ในโฟลเดอร์ย่อย)

**วิธีใช้ Git (ผ่านคำสั่ง)**

```bash
git clone https://github.com/<ชื่อผู้ใช้>/e-portfolio.git
cd e-portfolio
# คัดลอกไฟล์ทั้งหมดมาไว้ในโฟลเดอร์นี้ แล้วรันต่อ
git add .
git commit -m "Add e-portfolio website"
git push origin main
```

### 2) เปิดใช้งาน GitHub Pages

1. ใน Repository กดแท็บ **Settings**
2. เมนูด้านซ้าย เลือก **Pages**
3. ที่หัวข้อ **Build and deployment** → **Source** เลือก **Deploy from a branch**
4. ที่ **Branch** เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอประมาณ 1–3 นาที แล้วรีเฟรชหน้า Pages จะแสดงลิงก์เว็บไซต์ของคุณ

### 3) เข้าชมเว็บไซต์

```
https://<ชื่อผู้ใช้>.github.io/e-portfolio/
```

ตัวอย่างสำหรับบัญชี `teamlol55`: `https://teamlol55.github.io/e-portfolio/`

### แก้ไขภายหลัง

เมื่อแก้ไขไฟล์แล้ว อัปโหลดหรือ `git push` ใหม่ GitHub Pages จะอัปเดตเว็บให้เองภายในไม่กี่นาที
(ถ้าไม่เห็นการเปลี่ยนแปลง ให้กด Ctrl+F5 หรือ Cmd+Shift+R เพื่อล้างแคช)

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|-------|---------|
| เปิดลิงก์แล้วขึ้น 404 | ตรวจว่า `index.html` อยู่ระดับนอกสุด และรอสักครู่หลังเปิด Pages |
| หน้าเว็บไม่มีสไตล์ | ตรวจว่าชื่อไฟล์ `style.css` และ `script.js` ตัวพิมพ์เล็กตรงกับใน `index.html` |
| รูปไม่ขึ้น | ตรวจ path ของรูป เช่น `images/profile.jpg` ให้ตรงกับชื่อไฟล์จริง (แยกตัวพิมพ์ใหญ่เล็ก) |
| ฟอนต์เปลี่ยนไป | ตรวจการเชื่อมต่ออินเทอร์เน็ต เพราะฟอนต์โหลดจาก Google Fonts |
